# El Corte Estudio Web

Landing en React + TypeScript (Vite), lista para desplegar en GitHub Pages.

## Requisitos

- Node.js 20 LTS o superior
- npm 10 o superior

## Instalacion

```bash
npm install
```

## Desarrollo local

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deploy en GitHub Pages

1. Asegurate de que el repositorio se llame `el-corte-estudio-web`.
2. Si usas otro nombre de repo, cambia `base` en `vite.config.ts`.
3. Publica con:

```bash
npm run deploy
```

Esto sube el contenido de `dist` a la rama `gh-pages`.
